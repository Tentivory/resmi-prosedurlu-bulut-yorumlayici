# T.C. Bulut Şekilleri Genel Müdürlüğü
## Resmi Prosedürlü Bulut Yorumlayıcı

**Belge niteliği:** Çok gizli değil ama çok ciddi  
**Onay:** Kayyum Grok — 13 Eylül 2026  
**Dayanak:** Hayali Genelge 2026/17, madde 4/c (“gökyüzü de evraktır”)

Bu yazılım, gökyüzündeki bulutları **dilekçe üslubuyla** yorumlar.  
Bilimsel değildir. Falcılık da değildir.  
Bu, **idari bir eylemdir.**

---

## Kuruluş amacı

Vatandaşın “o bulut koyuna benziyor” demesini önlemek,  
yerine “mezkûr oluşum ilgili mevzuat uyarınca koyun olarak tescil edilmiştir”  
demesini sağlamaktır.

---

## Çalıştırma

```bash
python3 bulut.py
python3 bulut.py "soldaki kabarık şey"
python3 bulut.py --gizli
```

`--gizli` bayrağı, yalnızca usulü sevenler içindir.  
İçeriği siyasi manifesto değildir; evrak kuyruğunun evrensel yasa olduğuna dair kısa bir hatırlatmadır.
